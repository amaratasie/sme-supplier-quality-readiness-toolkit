# SME Supplier Quality Readiness Toolkit

Public download site for the SME Supplier Quality Readiness Toolkit by Amarachukwu (Amara) Tasie.

The site contains an APQP launch timeline, a simplified PPAP preparation checklist, a supplier scorecard, and an 8D corrective action guide. The first three tools are in one editable workbook; the guide is a Word document. The complete package and detailed usage instructions are in `files/`.

This is an original educational toolkit for manufacturers with fewer than 200 employees. It does not replace customer-specific requirements, governing quality manuals, regulatory obligations, or an authorized customer approval. It contains no employer or customer data and no claimed SME pilot results.

## Publishing with GitHub Pages

This repository is designed as a project site named `sme-supplier-quality-readiness-toolkit`. The site entry point is `index.html` at the repository root, and download links use relative paths so they work at `https://amaratasie.github.io/sme-supplier-quality-readiness-toolkit/` after Pages is enabled. Select **Deploy from a branch**, choose `main`, and publish from `/ (root)` in the repository's **Settings → Pages**. Wait for GitHub to show the final URL before sharing it.

The actual published URL depends on repository ownership, name, and Pages settings. The URL above is a planned address, not evidence of publication.
